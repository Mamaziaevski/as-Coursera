## Повторяющиеся особенности

- Отдельные файлы для API, моделей, схем и ИИ-логики.
- Router с понятным назначением: user_router, predict_router, ai_router; встречается и просто router.
- Схемы с именами InputSchema, OutputSchema, CreateSchema, UpdateSchema. Также встречаются короткие имена UserOut и UserUpdate.
- Обычные функции и async def с декораторами; зависимости Depends передаются явно.
- Работа с базой через локальные переменные user_db, current_user и понятную последовательность проверок.
- Словари, списковые включения, setattr и вспомогательные функции уже используются. Поэтому их сохранение соответствует твоему пожеланию не раздувать код.
- HTTPException часто написан с именованными аргументами status_code и detail.
- Строки и форматирование различаются между проектами. Выбран читаемый общий вариант, без копирования случайных опечаток и устаревших вызовов.

## Что адаптировано

Черновик разделён на agent_schema.py, agent_tools.py, agent_chain.py и api/agent.py. Используется agent_router и схемы с суффиксом Schema. Для запуска добавлен обычный импорт router вместо динамического importlib. Работа с базой, правила доступа и формат HTTP-маршрутов сохранены.

В исходных папках встречаются разные стили; просмотр кода сам по себе не подтверждает авторство каждого файла. Эти выводы описывают повторяющиеся особенности доступных примеров, а не единственный неизменный стиль.
