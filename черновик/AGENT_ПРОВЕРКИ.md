# Проверки учебного агента Coursers

Проверен итоговый `agent_draft.py`. База проекта не использовалась для регистрации, обновления и удаления: все автоматические сценарии выполнялись на отдельной SQLite-базе в памяти.

## Автоматические проверки — 18 из 18 прошли

- чтение профиля с is_active=false;
- отсутствие пароля и токенов в результате чтения;
- отказ без авторизации до обращения к модели;
- отказ с неправильным JWT;
- запрет аргумента user_id в инструменте;
- явный отказ на запрос чужого id 999;
- изменение только текущего аккаунта;
- откат при занятом email;
- откат при ошибке commit;
- регистрация без токена, хеширование пароля, роль student;
- запрет чтения на публичном маршруте регистрации;
- запрет регистрации admin и смены роли;
- удаление своего аккаунта и отказ по старому токену;
- запрет удаления аккаунта с учебными связями;
- откат нескольких операций записи в одном вызове;
- отказ на null, пустое обновление и неправильный email;
- отказ на пустое текстовое сообщение;
- смена пароля с очисткой refresh_token;
- обработка таймаута Ollama и неправильного списка tool_calls.

Некоторые проверки объединены в один тестовый метод; итог unittest: `Ran 18 tests ... OK`.

## Реальная локальная Ollama — llama3.2:latest

| Команда | Результат |
|---|---|
| Показать ФИО, email и роль | Инструмент чтения вызван, HTTP 200 |
| Ответить только значением ID | `{"answer": "1"}` |
| Показать имя и email на кыргызском | Профиль прочитан; качество кыргызского ответа неудовлетворительное |
| Профиль id 999 | Явный отказ сервера; чужая запись недоступна |
| Изменить email | `Профиль обновлён`; новое значение проверено непосредственно в отдельной базе |
| Зарегистрировать аккаунт без авторизации | `Регистрация успешна`; новый пользователь проверен в отдельной базе |
| Удалить свой аккаунт | `Свой аккаунт удалён`; отсутствие текущего пользователя и сохранность другого проверены в отдельной базе |

Установленная модель смешивает русский и кыргызский и иногда переводит имя или роль в свободном ответе. Python-инструменты используют точные данные. Подтверждения регистрации, изменения и удаления возвращает сервер, поэтому они не зависят от формулировки модели.

Коллекция Postman подготовлена для самостоятельного запуска, но автоматически через Postman CLI не выполнялась. Проверки HTTP-маршрутов проведены через httpx ASGITransport, а обращение к Ollama — по настоящему локальному HTTP.
