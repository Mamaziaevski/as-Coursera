6. Refresh-токен сохраняется в базе; повторный вход заменяет его, logout отзывает.
7. Вход не блокирует студента с is_active=False: для него доступны только free-курсы.

10. Добавлен POST /enrollments/ с group_id в JSON; прежний маршрут

11. Категории требуют роль admin, согласно Category CRUD: ADMIN.
12. Убрано повторное подключение SQLAdmin.

14. Поиск неизвестного курса не возвращает случайные курсы из базы знаний.

## Что делать в Postman дальше

1. Перезапустить FastAPI, чтобы загрузить новый код и настройки .env.
2. POST http://127.0.0.1:8000/auth/login/ с учётными данными преподавателя.
3. В Authorization выбрать Bearer Token и вставить access_token.
4. POST http://127.0.0.1:8000/courses/ — Body → raw → JSON:

```json
{
  "title": "Python для начинающих",
  "category_id": 1,
  "description": "Базовый Python",
  "level": "beginner",
  "price": 0,
  "duration_weeks": 4,
  "is_active": true,
  "status": "free"
}
```

category_id должен существовать. teacher_id и даты вручную не передаются.
Ожидается 201 Created, объект курса с id, teacher_id и заполненным updated_at.
**Следующим сообщением показать ответ на этот запрос: статус и JSON.**

5. GET /courses/{id}/ — проверить созданный курс; Body → none.
6. PUT /courses/{id}/ — отправить все поля курса, изменив price на 5000.
7. POST /groups/ с токеном преподавателя:

```json
{
  "name": "Python-1",
  "course_id": 1,
  "capacity": 15,
  "starts_on": "2026-11-01",
  "ends_on": "2026-11-29",
  "status": "recruiting"
}
```

course_id заменить полученным ID курса.

8. Войти как студент и POST /applications/:

```json
{"course_id": 1, "comment": "Хочу учиться"}
```

9. Войти как менеджер: GET /applications/ и PATCH /applications/{id}/:

```json
{"status": "accepted", "comment": "Заявка одобрена"}
```

10. Войти как студент и POST /enrollments/:

```json
{"group_id": 1}
```

group_id заменить полученным ID группы. Затем GET /enrollments/ и GET /auth/me/.
GET-запросы отправлять с Body → none.

11. POST /search/:

```json
{"question": "Найди курс по Python для начинающих beginner"}
```

Поиск пока использует courses.json, а не новые курсы из SQL-базы.

## Текущие ограничения

- Просмотр активных курсов открыт; изменение — преподавателю-владельцу.
- Группу создаёт преподаватель, студент записывается в существующую группу.
- Для произвольных формулировок поиска результат зависит от локальной модели.
- SQLAdmin проверен на открытие; его отдельная авторизация в эту проверку не входила.
- Сохранён привычный стиль datetime.utcnow; Python сообщает о его устаревании.
